# 🐍💧🔫 Snake Water Gun Game

A simple Python command-line game — a twist on the classic Rock-Paper-Scissors, where **Snake, Water, and Gun** battle it out!

## 🎮 Rules

- 🐍 **Snake** drinks **Water** → Snake wins
- 💧 **Water** short-circuits the **Gun** → Water wins
- 🔫 **Gun** kills the **Snake** → Gun wins
- Same choice by both → It's a draw

## 🛠️ Tech Used

- Python 3
- `random` module (built-in)

## 🚀 How to Run

1. Clone this repository
   ```bash
   git clone https://github.com/vishalltomar/<repo-name>.git
   cd <repo-name>
   ```
2. Run the script
   ```bash
   python game.py
   ```
3. Enter your choice when prompted:
   - `s` for Snake
   - `w` for Water
   - `g` for Gun

## 📸 Sample Output

```
Computer's turn: Snake(s), Water (w), Gun (g)
Your turn: Snake(s), Water (w), Gun (g): s

You chose: s
Computer chose: w

You win!
```
